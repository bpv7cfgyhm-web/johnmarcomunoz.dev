Tools built for a real shop floor

Procurement used to live in email threads and a shared spreadsheet. This tool stores every RFQ, the vendors it went to and each response, then ranks quotes by price, lead time and past on-time delivery. Buyers see what's overdue at a glance, and the history makes the next quote faster.

  • Side-by-side quote comparison with landed-cost math
  • Automatic reminders for vendors that haven't responded
  • Vendor scorecards built from real delivery history
  • Python
  • Flask
  • SQLite
  • HTMX

Small collectors on each machine report cycle state to a central service. The board shows utilization by shift, flags machines that have sat idle too long, and keeps a history so downtime conversations start from data instead of memory.

  • Per-machine run / idle / alarm state with timestamps
  • Shift utilization summaries emailed each morning
  • Runs on low-cost hardware mounted at the machines
  • Raspberry Pi
  • Python
  • MQTT
  • Node.js
  • Chart.js

Inserts, end mills and bar stock are tracked with cheap barcode scanners. When a quantity falls below its reorder point, a draft purchase request is created with the preferred vendor and last price filled in, so nothing runs out mid-job.

  • Scan-to-issue workflow that takes seconds at the crib
  • Min/max reorder points per item and per job
  • Usage reports that feed tooling budget decisions
  • Python
  • PostgreSQL
  • Barcode scanners
  • Power Automate

Pulls open work orders from the ERP export, estimates run time from routing data, and lays jobs out on a per-machine timeline. Jobs at risk of missing their ship date turn amber well before they turn into a problem.

  • Imports nightly ERP exports automatically
  • Capacity view per machine and per shift
  • Late-risk warnings based on remaining operations
  • JavaScript
  • Node.js
  • SQL
